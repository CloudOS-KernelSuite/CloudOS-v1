## 🌟 Overview
**CloudOS** è un ambiente operativo modificato per Windows, progettato per massimizzare le performance e garantire la massima sicurezza. È la soluzione definitiva per chi cerca un sistema reattivo, privo di bloatware e pronto per il gaming competitivo.

## 🚀 Caratteristiche Principali
* ⚡ **Performance:** Kernel-level tweaks per latenza minima e max FPS.
* 🛡️ **Anti-Cheat:** Architettura sicura e trasparente per BattlEye ed EAC.
* 🔒 **Security:** Hardening avanzato contro inject e vulnerabilità di sistema.
* 🛠️ **Smart Set Up:** Installazione fluida e configurazione rapida in pochi minuti.

## 🖥️ Requisiti Minimi di Sistema
Per garantire la stabilità e le performance di CloudOS, il tuo hardware deve soddisfare i seguenti standard:

| Componente | Requisito |
| :--- | :--- |
| **Processore** | 1 GHz o superiore, 2+ core (64-bit / SoC) |
| **RAM** | 4 GB |
| **Archiviazione** | 64 GB disponibili |
| **Firmware** | UEFI & Secure Boot (Avvio Protetto) |
| **Modulo** | TPM (Trusted Platform Module) v2.0 |
| **Grafica** | Compatibile DirectX 12 / Driver WDDM 2.0 |
